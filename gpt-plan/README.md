- `instagram-review/publication-plan-180-posts/`: **güncel** 180 gönderi planı, ilk 14 gün, profil girişi ve tüm caption/metin dosyaları.
- `instagram-review/planning-180-posts/`: planı yazan veri ve üretim kaynakları.

- `research/`: planın dayandığı `u320x` araştırmasının kullanılan `23e3dd0cb7effcaec2904d5ddeb49e9888abb0a5` sürümü. Kaynakların o tarihteki durumu korunur; yeniden doğrulanmış güncel araştırma değildir.
- `instagram-review/working/`, eski `publication-plan-180*` klasörleri: önceki strateji ve tarihsel taslaklar; güncel planın yerine kullanılmaz.
- `assets/`: planlarda geçen eserlerin web kopyaları ve video kaynak önizlemeleri.

Görseller oranları korunarak, ICC görünümü sRGB'ye dönüştürülerek WebP web kopyalarına alınmıştır. Özgün yerel arşiv dosyaları değiştirilmemiştir. SVG kapaklardaki tekrar eden gömülü görseller ortak dosyalara bağlanmıştır; ilgili SVG ve assets klasörleri birlikte tutulmalıdır. Yerel dosya bağlantıları paket içi bağıl bağlantılarla değiştirilmiştir. Son render videoları, sesler, API anahtarları ve bağımlılık kurulumları aktarılmamıştır.
